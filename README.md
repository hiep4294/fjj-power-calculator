# FJJ Power Calculator

Công cụ độc lập tính số nguồn/mạch cấp cho động cơ FJJ.

## Chức năng
- Chọn loại động cơ FJJ.
- Nhập số lượng động cơ.
- Nhập tổng chiều dài tuyến.
- Chọn tiết diện dây đồng.
- Dự phòng dòng cố định 15%.
- Kiểm tra dòng tải và sụt áp 3%.
- Tự chia số motor trên từng nguồn/mạch.
